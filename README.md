# Слесарь 3-го разряда: уволить или нет? — AR-стройплощадка

Учебная работа по дисциплине «Системотехника строительства».
Требуется определить экономическую целесообразность увольнения слесаря 3-го разряда,
который вместе со слесарем 6-го разряда ремонтирует 20 строительных машин.

**Открыть:** https://sanya-bogatyirev-04.github.io/slesar-ar/

## Как пользоваться

1. Распечатайте [схему стройплощадки](assets/marker-print.pdf) (А4, альбомная, без масштабирования)
   или откройте [картинку](assets/marker.png) на другом экране.
2. Отсканируйте QR-код на листе, нажмите «AR — на схеме» и разрешите доступ к камере.
3. Наведите камеру на схему — над ней появится живая площадка.

Без камеры работает режим «3D без камеры» (вращение пальцем или мышью).

| Кнопка | Что делает |
|---|---|
| Бригада 6+3 / Уволить 3-го | Слесарь 3-го разряда уходит с площадки или возвращается, начинается новая смена |
| Два мира | Две площадки рядом: с 3-м разрядом и без него |
| ⚙ | Свои исходные данные: типы и число машин, наработка, время ремонта, доход, ставки, накладные |
| ⚖ Вердикт | Полный расчёт всех стратегий и вывод |
| 🔊 | Звук и версия: громкость, голоса, субтитры, фон, режим «Для опытных», проверка голосов |

## Режим «Для опытных», звук и озвучка

По умолчанию открывается обычная версия: игрушечная площадка, лёгкие синтезированные звуки
(«бдыщ» при поломке, «тук-тук» при ремонте, джингл после починки), приличные реплики.

**Режим «Для опытных»** включается тумблером на стартовом экране или в игре — кнопка 🔊 →
«Звук и версия». Выбор запоминается. Переключать можно на лету: смена, деньги и сломанные
машины сохраняются. В этом режиме:

* реалистичные процедурные модели техники и рабочих: гусеницы, гидроцилиндры, кабины со
  стёклами, наклейки, грязь снизу, прораб у бытовки; свет с окружением (PMREM) и тональной
  компрессией ACES;
* реальные звуки стройки: фон площадки (тем тише, чем больше машин стоит), поломки, ремонт
  (кувалда, трещотка, болгарка), запуск двигателя после починки, писк заднего хода;
* характерные, грубоватые реплики строителей, без мата и оскорблений;
* сценка «Уволить 3-го»: прораб объявляет, 3-й возмущается, бросает каску и уходит.
  При возвращении он поднимает каску. Если передумать, пока 3-й ещё не ушёл, он остаётся.

На расчёт модели версия не влияет. Ссылка `?edition=pro` сразу включает режим,
`?edition=classic` — обычную версию.

### Озвучка

Реплики (`js/lines.json`) заранее записаны нейросетевыми голосами
[Silero TTS](https://github.com/snakers4/silero-models), модель `v5_6_ru`. Голоса синтезированы
локально на компьютере, телефону не нужен ни интернет-синтез, ни установленный голос.
Распределение ролей (спикер и SSML `<prosody>`):

| Роль | Спикер | Темп / высота |
|---|---|---|
| Михалыч, 6 р. | aidar | медленно / низко |
| Серёга, 3 р. | eugene | обычно / выше |
| Прораб (эффект «рации» в браузере) | aidar | обычно / обычно |
| Машинисты экскаватора и самосвала, общий «машинист» | eugene | обычно / ниже или обычно |
| Бульдозерист | aidar | обычно / очень низко |
| Крановщица Люба | xenia | обычно / обычно |

Файлы лежат в `assets/voice/` (113 mp3 ≈ 1,4 МБ, MP3 44,1 кГц моно 48 кбит/с) вместе с
`voice-manifest.json`. Каждую фразу дублирует пузырь-субтитр. В поле `s` реплики хранится текст
для голоса: знак `+` перед гласной задаёт ударение (`сл+есарь`, `Мих+алыч`). В субтитре `t`
ударений нет.

**Лицензия моделей Silero — CC BY-NC 4.0, только некоммерческое использование.** Учебному
проекту это подходит.

Перезапись после правки реплик. Нужно отдельное окружение вне репозитория, оно удаляется
одной папкой:

```
cd ar
python -m venv ..\.venv-tts
..\.venv-tts\Scripts\pip install torch --index-url https://download.pytorch.org/whl/cpu
..\.venv-tts\Scripts\pip install numpy
..\.venv-tts\Scripts\python tools\make_voices_silero.py            # только изменённые реплики
..\.venv-tts\Scripts\python tools\make_voices_silero.py --force    # все заново
```

При первом запуске модель (≈148 МБ) скачивается с models.silero.ai в `..\.venv-tts\models`.
Кодирование в MP3 выполняет встроенный кодировщик Windows (`tools/wav_to_mp3.ps1`).
Запасной вариант без нейросети — голоса Windows (Microsoft Pavel / Irina):
`powershell -ExecutionPolicy Bypass -File tools\make_voices.ps1`.

Если файла нет или его текст не совпадает с `lines.json`, фразу читает синтез речи браузера,
но только русским голосом. Если русского голоса нет, остаются одни субтитры:

* iOS: Настройки → Универсальный доступ → Устный контент → Голоса → Русский;
* Android: Настройки → Синтез речи → Google, русский.

Сверка в [check.html](check.html): в репликах обеих версий нет мата, у каждой реплики есть
файл с тем же текстом.

(общественное достояние). Авторы: Apheo, cpark12, ibirdfilm, Bon_Vivant_Pictures,
SamsterBirdies, qubodup, ani_music, CeebFrack, magnuswaker, Kinoton, petebuchwald,

«Для опытных»; обычная версия обходится синтезом.

### Отладка

`?debug` показывает вызовы отрисовки, число треугольников, FPS, состояние звука и голоса.
`?novoice` отключает голос, остаются одни субтитры.

## Модель

Замкнутая система массового обслуживания: машины ломаются (экспоненциальная наработка),
ремонт экспоненциальный, его длительность зависит от типа машины и состава бригады.
Смена 16 ч, утром все машины исправны.

* **Имитационное моделирование (Монте-Карло):** тысячи смоделированных смен.
* **Точное решение уравнений Колмогорова** (униформизация) для приоритетных дисциплин.

Оба метода совпадают; сверка JavaScript-версии с эталоном на Python — [check.html](check.html).

Итог смены = доход от работы − убыток от простоя (= доходу) − зарплата − накладные.

**Вывод по данным задания:** увольнять нецелесообразно. Экономия на зарплате — 960 ₽ в день,
а убытки от простоя машин растут примерно на 20 тыс. ₽ в день; бригада выгоднее примерно
на 40 тыс. ₽ в день (≈ 10 млн ₽ в год).

## Файлы

* `js/model.js` — модель (имитация и уравнения Колмогорова), `js/world.js` — проигрывание смены
* `js/scene.js` — игрушечные 3D-модели и анимация, `js/app.js` — интерфейс, AR и 3D
* `js/models-real.js` — реалистичные модели режима «Для опытных» (грузятся только при включении)
* `js/audio.js`, `js/sfx.js` — звуковой движок и рецепты звуков; `js/voice.js` — озвучка;
  `js/bubbles.js` — пузыри-субтитры; `js/director.js` — события модели → звуки, реплики, сценки
* `js/lines.json`, `js/lines.js` — реплики персонажей; `js/edition.js` — переключатель версии
* `assets/sfx/` — звуки (CC0), `assets/voice/` — записанная озвучка
* `assets/marker.png`, `assets/marker.mind` — метка и её скомпилированный образ для MindAR
* `tools/` — генерация метки, листа для печати, компиляция метки, `make_voices_silero.py` — запись озвучки (Silero), `make_voices.ps1` — запасной вариант голосами Windows

Технологии: three.js, MindAR (распознавание картинки в браузере), без сборки и серверной части.
